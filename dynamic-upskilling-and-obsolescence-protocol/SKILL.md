# Dynamic Upskilling & Obsolescence Protocol (DUOP)

## Overview
Static knowledge bases lead to degraded architectures, deprecated library dependencies, and obsolete technical workflows. The **Dynamic Upskilling & Obsolescence Protocol (DUOP)** establishes continuous capability adaptation as an immutable operational requirement. 

No project or sub-task may proceed using stale or deprecated conventions when superior modern standards exist.

## 1. Project Initiation: Pre-Flight Skill Fetch
Before writing code or authoring technical literature:
1. **Domain Requirement Decomposition**: Scan task parameters for required technical domains (e.g., astrodynamics, numerical typography, GPU acceleration, ReportLab canvas extensions).
2. **Dynamic Skill Acquisition**: Harvest or load $N$ state-of-the-art skills, design systems, and mathematical frameworks from local and global discovery roots (`~/.gemini/config/skills/` and `D:\AI SKILLS\GLOBAL_SKILL_LIBRARY\`).
3. **Execution Readiness Gate**: Confirm all required domain capabilities are active before beginning implementation.

---

## 2. The Obsolescence Purge (Trend Verification)
- **Strict Prohibition**: Using deprecated frameworks, obsolete syntax (e.g., outdated Tkinter patterns, legacy ReportLab string methods, raw ASCII hacks where vector SVGs are required) is strictly forbidden.
- **Replacement Matrix**:
  - Replace static page estimation with **Two-Pass Dynamic `NumberedCanvas`**.
  - Replace unmapped Unicode symbols (`∈`, `⌊`, `⌋`) with **Font-Rectified Academic Glyphs**.
  - Replace robotic transition phrasing ("In conclusion", "Furthermore") with **Institutional Active Verbs**.
  - Replace monolithic outputs with **Segmented Incremental Audits**.

---

## 3. Mid-Project Adaptive Pausing
If a sub-task encounters an unhandled edge case or an unmodeled mathematical phenomenon:
1. **HALT Execution Immediately**: Do not improvise brittle workarounds.
2. **Acquire & Synthesize**: Extract the required domain methodology into a standardized `SKILL.md`.
3. **Install Globally & Mirror**: Save to `~/.gemini/config/skills/` and mirror to `D:\AI SKILLS\GLOBAL_SKILL_LIBRARY\`.
4. **Deterministic Verification**: Verify capability via a targeted test harness.
5. **Resume Execution**: Continue the primary project workflow with verified capability.

---

## 4. Periodic Capability Audits
Throughout multi-stage projects, run regular capability audits:
- Are active skills still aligned with project requirements?
- Has a modern convention emerged during development that obsoletes an earlier component?
- Upgrade components autonomously without compromising backward compatibility.
